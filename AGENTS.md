# Avisos Abiertos · Última Milla

Preparar este MVP en Cloud. Instalar dependencias, ejecutar servidores, modelos,
indexación, pruebas y builds únicamente en el ejecutor remoto; el Mac del
usuario se usa para control, revisión y transporte de archivos pequeños.

Usar TypeScript para código nuevo. Este repositorio es público: incorporar
solo fuente y documentos listos para distribución, sin credenciales, evidencias
de usuarios, contactos ni corpus internos. Preservar licencias de dependencias.

Mantener UI, REST y MCP bajo el mismo contrato, con persistencia y permisos por
objeto. Documentar qué integra realmente cada ruta, su autenticación y límites.
Un registro propio no prueba recepción oficial; un antecedente no acredita
responsabilidad ni probabilidad. Las pruebas usan avisos de prueba y no generan
envíos a organismos.

Marca Última Milla: blanco, negro, gris y acento #DC2626, logotipo en minúsculas
ultimamilla.com.ar con los dos puntos rojos. UI móvil breve y usable.

El prototipo privado C3/SITREP y su historial están en otro repositorio y otro
Site. No importar su historia, abrir su audiencia ni modificar producción.
Para Sites, usar únicamente el helper original instalado y sus operaciones
nativas; una denegación no autoriza otro mecanismo de publicación.
